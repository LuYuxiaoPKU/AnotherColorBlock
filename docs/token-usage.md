# Token 消耗统计（AnotherColorBlock 社区维护线）

> 数据来源：Claude Code 会话 transcript 的 usage 字段逐条汇总（脚本 `test/usage-report.py`，可随时重跑）。
> 统计范围：Fabric 线 + NeoForge 线两个会话的全部本地会话记录（42 个会话文件）。
> 本地记录最早始于 2026-10-09（更早的 1.21.x/1.20.x 战役记录已被清理），真实全周期消耗只多不少。

## 总量（2026-10-09 ~ 10-16）

| 口径 | 数值 |
|---|---|
| API 调用 | 25,460 次 |
| 未命中输入（全价） | 254.3M tokens |
| 缓存命中输入（约 1/10 价） | 4552.6M tokens |
| 输出（含思考） | 14.90M tokens |

## 说明

- 缓存命中输入按多数供应商约 1/10 价计费，是本次开发成本的大头但单价极低。
- 由于 API 经多层转发，transcript 中记录的模型名已不可信，故不做按模型拆分；实际接入模型见 README「AI 辅助开发声明」。
- 最终产出：代码 81 文件约 387 KB + 文档约 105 KB；55 个实机测试站（Fabric 37 + NeoForge 18）。
